## 第 2 章：安装与首次启动

### 2.1 系统要求
Titan Edition 轻巧，可在 Windows 和 Linux 上运行：

-   **Windows：** Windows 10 或更高版本（64 位）。
-   **Linux：** Ubuntu 22.04+、Debian 及其衍生版可通过 `.deb` 软件包安装；在其他发行版上，请使用 `.AppImage` 格式，它独立自足、无需安装。

*注意。* 在某些较新的 Ubuntu 版本上，`.AppImage` 需要 `libfuse2` 软件包；如果无法启动，请安装它（`sudo apt install libfuse2`）或改用 `.deb`。

*注意。* Titan 也可以在没有独立显卡的 Virtual Private Server 上运行。如果启动时界面没有出现，一个安全机制会在约十秒后强制显示它（我们将在第 9 章讨论）。

### 2.2 安装
安装很简单。

1. 从项目的发布页面下载安装程序。您也可以自行从源代码编译。
2. **在 Windows 上：** 运行 `.exe` 文件并按照屏幕上的说明操作。程序会自行在桌面上创建一个快捷方式。
3. **在 Linux 上：** 使用 `.deb` 软件包时，双击并交给包管理器处理；使用 `.AppImage` 时，把文件设为可执行（右键 → 属性 → 权限 → 允许执行），然后双击打开。

安装完成后，您无需再手动下载任何东西：Titan 会自行检查是否有更新版本，找到时会通过一个专门的界面提示您，询问是否下载，下载完成后再询问是否重启以安装。

![可用更新提示：Titan 在下载前和重启前都会请求确认。](screenshots/11-update-available.png)

### 2.3 Setup Wizard（首次启动）
在最初一次启动时，经过动画启动序列和语言选择之后，Titan 会以一个分四步的设置向导（Setup Wizard）迎接您，帮助您立即配置好第一个自动化流程。

![设置向导分四步引导您完成第一个机器人的配置。](screenshots/02-setup-wizard.png)

1.  **机器人名称：** 一个描述性名称，帮助您在界面中识别该配置（例如"体育新闻机器人"）。它不会对您在 Telegram 上的用户可见。
2.  **机器人令牌：** 在此粘贴由 `@BotFather` 生成的秘密令牌。*（如何获取，详见第 4.2 节。）*
3.  **频道 ID（Channel ID）：** 频道的公开用户名，前面加上 @ 符号（例如 `@mychannel`）。如果频道是私密的，请输入其数字标识，通常以减号开头（例如 `-100123456789`）。
4.  **开始日期（Start Date）：** 一个重要参数。默认是今天的日期：Titan 仍会读取您的源，但会**忽略并丢弃**此日期之前发布的任何新闻或视频。这可以避免机器人在首次启动时用几周前的旧闻淹没频道。

完成这四步后，点击 **启动 Titan**：您将进入主控制台。

### 2.4 欢迎界面：语言、指南与手册
八面旗帜的界面并非只属于首次启动：每次开启它都会出现，您在那里选择界面语言，切换立即生效。**启动 Titan** 按钮带您进入。

该按钮下方有三个快捷入口：

-   **快速指南** 会在屏幕上打开一份几页的摘要，使用您所选的语言：如何从 @BotFather 获取令牌、向导的四个步骤、如何添加来源、如何自定义消息，以及如何启动引擎。它面向想要立刻上手、不打算通读本手册的人。
-   **下载手册 (PDF)** 会在系统浏览器中打开您所用语言的完整手册——也就是您正在读的这一本。该文件并不在应用程序内部：它是在那一刻从网络获取的，因此需要有效的网络连接。
-   **支持本项目** 会打开自愿捐赠页面。Titan 免费且开放源代码：捐赠完全自愿，不会解锁任何功能。

这两个文档入口在系统设置的 **常规** 选项卡中也能找到（第 8.2 节）。

### 2.5 更新之后："新功能"界面
当 Titan 完成自我更新后，新版本首次启动时会显示一个整屏页面，列出改动内容：修复、新功能、行为变化。版本号处于醒目位置，列表使用您的语言，**继续** 按钮将其关闭。

它每个版本只出现一次：关闭之后，直到下一次更新到来才会再见到它。如果某个版本没有自己的列表，取而代之的是一行通用说明，提示修复与稳定性改进。
