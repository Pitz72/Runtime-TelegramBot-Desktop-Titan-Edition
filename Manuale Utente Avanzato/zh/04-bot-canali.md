## 第 4 章：管理机器人与频道

### 4.1 创建多个机器人
Titan 是多频道的：您可以在同一个窗口中管理多个机器人，每个都有自己的频道。假设您经营一家电台：您需要一个 Telegram 频道用于文字新闻（News），一个用于音频节目（Podcast），也许还有第三个用于幕后花絮（YouTube）。您无需安装程序三次。

在机器人那一列的顶部、右侧，有一小组命令。**+** 会打开一个快速表单：输入名称、令牌、频道 ID 和开始日期，保存后新配置就会出现在列表中。**+** 旁边还有一个按钮，用于从 `.rtb` 文件**导入**机器人（第 7 章），以及一个滑块按钮（🎚️），用于打开其**设置**（第 6 章）。

每个配置都独立存在：源、时间安排和模板都是分开的。当您按下 Play，Titan 会在一个统一的工作循环中调度所有活跃的机器人，轮流为它们服务。

### 4.2 从 @BotFather 获取令牌
**Bot Token**（机器人令牌）是让软件与 Telegram 服务器对话的"家门钥匙"。要获取一个，您需要 Telegram，手机或电脑均可：

1. 在 Telegram 搜索中输入 `BotFather`，打开那个官方资料页，可通过蓝色验证勾标识。
2. 按 **开始**，发送命令 `/newbot`。
3. BotFather 会先要一个"名称"（用户会看到的那个），再要一个唯一的"Username"，它必须以 *bot* 一词结尾（例如 `myradio_news_bot`）。
4. 如果该 username 可用，BotFather 会回复一条祝贺消息，其中包含一长串字母数字字符串，位于 *Use this token to access the HTTP API* 字样之下。
5. 复制该字符串：这就是要粘贴到 Titan 中的令牌。

**重要。** 切勿分享令牌。Titan 会将其加密保存，通过操作系统的密钥环把它绑定到这台电脑：这样，即便把程序文件复制到另一台机器上，令牌仍无法读取。要真正把它迁移到另一台电脑，可使用 `.rtb` 格式，详见第 7 章。

### 4.3 找到正确的 Channel ID
要发布，机器人必须知道该把消息发往*何处*：这就是 **Channel ID**（频道 ID）。

-   **公开频道。** 这是最简单的情况。如果频道有一个形如 `t.me/mychannel` 的链接，那么 Channel ID 就是 `@mychannel`。您甚至无需十分精确：Titan 会自行清理您粘贴的内容：去掉 `https://` 和 `t.me/` 前缀，并在缺少时补上 @ 符号。于是 `https://t.me/mychannel`、`t.me/mychannel` 和 `mychannel` 最终都变成 `@mychannel`。
-   **私密频道。** 它们没有公开名称：它们由 Telegram 分配的一串数字来标识，通常以减号开头（例如 `-1002345678912`）。要获取它，请把频道里的一条消息转发给像 `@getidsbot` 这样的免费服务机器人，它会回复您该会话的确切数字代码。这个数字原样粘贴即可。

*黄金法则。* 创建好频道并取得 ID 之后，且在**启动机器人之前**，进入 Telegram 频道的设置，打开**管理员**，找到您的机器人并以发送消息的权限把它添加进去。如果机器人不是管理员（或 ID 有误），它就无法在频道里写入：日志中会出现红色的 Telegram 错误（我们在第 9 章讲解），并且什么都不会被发布。
