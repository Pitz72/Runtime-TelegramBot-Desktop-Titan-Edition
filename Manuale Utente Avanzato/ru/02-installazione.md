## Глава 2: Установка и первый запуск

### 2.1 Системные требования
Titan Edition лёгкий и работает на Windows и Linux:

-   **Windows:** Windows 10 или выше (64-бит).
-   **Linux:** Ubuntu 22.04+, Debian и производные через пакет `.deb`; на других дистрибутивах используйте формат `.AppImage`, автономный и не требующий установки.

*Примечание для Linux:* на некоторых свежих версиях Ubuntu для `.AppImage` нужен пакет `libfuse2`; если он не запускается, установите его (`sudo apt install libfuse2`) или используйте `.deb`.

*Примечание для серверов VPS:* Titan может работать и на Virtual Private Server без выделенной видеокарты. Если при запуске интерфейс не появляется, механизм безопасности принудительно выводит его примерно через десять секунд (об этом мы говорим в Главе 9).

### 2.2 Установка
Установка проста.

1. Скачайте установщик со страницы выпусков проекта. Как вариант, вы можете собрать его сами из исходного кода.
2. **В Windows:** запустите файл `.exe` и следуйте инструкциям на экране. Программа сама создаёт ярлык на рабочем столе.
3. **В Linux:** с пакетом `.deb` дважды щёлкните и предоставьте работу менеджеру пакетов; с `.AppImage` сделайте файл исполняемым (правый клик → Свойства → Права → Разрешить выполнение) и откройте его двойным щелчком.

После установки вам больше не придётся ничего скачивать вручную: Titan сам проверяет, есть ли более новая версия, и, когда находит её, сообщает об этом отдельным экраном, спрашивая, скачивать ли её и, по завершении скачивания, перезапускаться ли для установки.

### 2.3 Setup Wizard (первый запуск)
При самом первом запуске, после анимированной последовательности загрузки и выбора языка, Titan встречает вас мастером настройки (Setup Wizard) из четырёх шагов, чтобы сразу подготовить вашу первую автоматизацию.

![Мастер настройки проводит через настройку первого бота в четыре шага.](screenshots/02-setup-wizard.png)

1.  **Имя Бота:** описательное имя, помогающее вам узнавать профиль в интерфейсе (напр. «Бот Спортивные Новости»). Оно не будет видно вашим пользователям в Telegram.
2.  **Токен Бота:** вставьте сюда секретный токен, сгенерированный `@BotFather`. *(Как его получить, объясняется в Главе 4.2.)*
3.  **ID Канала (Channel ID):** публичное имя пользователя канала с собачкой впереди (напр. `@mychannel`). Если канал приватный, введите его числовой идентификатор, который обычно начинается со знака минус (напр. `-100123456789`).
4.  **Дата начала (Start Date):** важный параметр. По умолчанию — сегодняшняя дата: Titan всё равно прочитает ваши фиды, но **проигнорирует и отбросит** любую новость или видео, опубликованные до этой даты. Это нужно, чтобы при первом запуске бот не завалил канал новостями недельной давности.

По завершении четырёх шагов нажмите **Запустить Titan**: вы окажетесь на главной панели управления.

### 2.4 Экран приветствия: язык и документация
Экран с восемью флагами появляется не только при первом запуске: он возвращается при каждом старте, и именно там вы выбираете язык интерфейса, который меняется мгновенно. Кнопка **Запустить Titan** проводит вас внутрь.

Под этой кнопкой три ярлыка:

-   **Краткое Руководство** открывает на экране сводку в несколько страниц, на выбранном языке: как получить токен у @BotFather, четыре шага мастера, как добавить источник, как настроить сообщения и как запустить движок. Она рассчитана на тех, кто хочет начать сразу, не читая это руководство.
-   **Скачать руководство (PDF)** открывает в системном браузере полное руководство — то самое, которое вы читаете, — на вашем языке. Файл не лежит внутри приложения: он забирается из сети в этот момент, поэтому нужно активное подключение.
-   **Поддержать проект** открывает страницу добровольного пожертвования. Titan бесплатен и имеет открытый исходный код: пожертвование необязательно и ничего не открывает.

Обе записи о документации вы найдёте и в Настройках Системы, на вкладке **Основные** (Глава 8.2).

### 2.5 После обновления: экран «Что нового»
Когда Titan обновился, при первом запуске новой версии появляется полноэкранная страница со списком изменений: исправления, новые функции, изменённое поведение. Номер версии вынесен на видное место, список — на вашем языке, а кнопка **Продолжить** закрывает его.

Он появляется один раз на версию: закрыв его, вы не увидите его снова до следующего обновления. Если у версии нет собственного списка, вместо него выводится общая строка об исправлениях и улучшениях стабильности.
