## Chapter 8: System Preferences

In the same gear window (⚙️) at the top right, the one that also hosts the Backup seen in Chapter 7, there are two preferences that apply to the whole application (not to the individual bot): the language and the graphical look. You will find them in the **General** and **Performance** tabs.

### 8.1 Interface language
In the **General** tab you choose Titan's language: Italian or English. Just click the matching flag and the interface changes at once.

A detail already met in Chapter 3: the log console stays in English whatever language you choose, so the technical messages remain a universal standard when you ask for support.

In the same tab you will find the **Check for updates** button, which forces an immediate check for a new version without waiting for the automatic one (Chapter 2). The installed version is always shown, with a marker when an update is available.

![The General tab of the System Preferences, with the language choice and the check-for-updates button.](screenshots/08-system-general.png)

### 8.2 Built-in documentation
Still on the **General** tab, the **Documentation** section gathers the two texts that ship with the program, the same ones you find on the welcome screen (Chapter 2.4).

-   **Quick Guide** opens on screen, in the current language, the essential summary for setting up the first bot without leaving the application.
-   **Download Manual (PDF)** opens the complete manual in your language in the system browser. The PDF is not part of the installation: it is fetched from the network on the spot, so an active connection is needed. If you change language and press the button again, you get the matching edition.

The same tab also holds the project **Credits** and the section for **supporting it**, with the link to the donation and the one to the contact page.

### 8.3 Performance Mode
Titan has a rich look: frosted glass, glows, old-monitor lines (the *scanlines*), animated transitions. They are pleasant, but on an older computer or a virtual machine they can weigh the graphics down.

The **Performance** tab has a switch that turns off the heaviest effects in one go: scanlines, blurs, glows and animations. The interface becomes plainer but more responsive, and the effect is immediate: no restart needed. Turn it on if you notice stutter or slowdowns, leave it off if the graphics run smoothly.
