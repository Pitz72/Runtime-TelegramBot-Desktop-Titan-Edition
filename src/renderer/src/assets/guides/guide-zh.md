# ⚡ Runtime TelegramBot Desktop Titan Edition: 快速入门指南

欢迎使用 **Runtime TelegramBot Desktop Titan Edition**。这份快速指南将帮助您在不到3分钟的时间内配置您的第一个机器人，并开始将内容发布到您的Telegram频道。

---

## 1. 准备工作：获取Telegram Token
在启动Titan之前，您必须在Telegram上创建一个"机器人"：
1. 打开Telegram并搜索用户 **@BotFather**（它有一个蓝色的验证徽章）。
2. 发送命令 `/newbot` 并按照说明给您的机器人命名。
3. 最后，@BotFather 会给您一个 **API Token**（一长串类似 `123456789:ABCdefGHIjklMNOpqr...` 的字符）。**复制并妥善保管它。**
4. 将新创建的机器人作为 **管理员** 添加到您的Telegram频道（它必须具有"发送消息"的权限）。

## 2. 首次启动（安装向导）
启动 Runtime TelegramBot Desktop Titan Edition。如果是第一次启动，将出现4步向导：
*   **机器人名称：** 选择一个名称以便识别它（例如，*新闻频道*）。
*   **Bot Token：** 粘贴由 @BotFather 提供的 Token。
*   **频道ID：** 输入您的频道名称（例如，`@mychannel`）。如果是私人频道，请输入数字ID（例如，`-100123456789`）。
*   **开始日期：** 选择一个日期。机器人 **将忽略** 在此日期之前发布的所有文章和视频，以避免用旧内容淹没您的频道。

## 3. 添加来源（Feed管理器）
进入仪表板后：
1. 确保在左侧列中选中了您的机器人。
2. 在 **Feed来源** 面板中，点击 **"+ 添加来源"**。
3. 输入名称（例如，*我的播客*）并选择 **类型**（播客、新闻或YouTube）。
4. 粘贴URL：
   * 对于新闻和播客：粘贴RSS feed的URL。
   * 对于YouTube：您可以直接粘贴频道URL或句柄（例如，`@RuntimeRadio`）。*不需要API密钥！*
5. 使用 **测试 (⚡)** 按钮验证链接是否有效，然后点击 **保存**。

## 4. 自定义消息（模板）
您希望您的帖子格式完美吗？
1. 点击左侧列中的 **设置 (⚙️)** 图标。
2. 转到 **模板** 选项卡。
3. 使用顶部方便的按钮面板插入自动变量，如 `{{title}}`、`{{link}}`或 `{{summary}}`。
4. 您可以使用Telegram支持的基本HTML标签，例如：`<b>粗体</b>`，`<i>斜体</i>`，或使用 `<a href="{{link}}">点击这里</a>` 将长链接隐藏在文本后面。

## 5. 启动（点火）
您已经输入了token并添加了feed了吗？您已准备就绪。
*   点击控制台中心的大 **播放 (▶)** 按钮。
*   光环将开始旋转，机器人将开始工作。
*   在 **System Logs** 面板中，您将实时看到机器人读取您的来源并向Telegram发布新内容！

### 💡 实用提示和故障排除
*   **免打扰时间：** 在机器人设置中，您可以定义活动时间。如果您设置为08:00至22:00，夜间新闻不会丢失，而是会排队并在早上08:00发布！
*   **YouTube错误：** 如果您在YouTube频道上收到"红色"错误，请不要惊慌。Google经常更新其服务器。通过界面中的专用按钮暂时关闭YouTube feed，并等待我们的软件更新。
*   **更换电脑：** 您需要将机器人移动到另一台计算机吗？不要复制文件！使用设置中的 **导出 (.rtb)** 功能。这将生成一个安全的文件以导入到新电脑中，同时保持您的密码加密。
