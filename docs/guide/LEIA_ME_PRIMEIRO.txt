=== INSTRUÇÕES DE INSTALAÇÃO RÁPIDA ===
Execute o ficheiro de instalação. O software instalará a interface
e criará automaticamente um atalho para o iniciar.
No primeiro arranque, um Assistente de Configuração guiá-lo-á passo a passo.

*** ATENÇÃO UTILIZADORES DO WINDOWS (SMARTSCREEN) ***
Titan Edition é um software independente, distribuído sem
intermediários. Na primeira execução do ficheiro «.exe», o Windows Defender
pode exibir uma janela azul com o texto:
«O Windows protegeu o seu PC - Fornecedor desconhecido».

Este é um procedimento normal de segurança do Windows para software
distribuído fora da Microsoft Store.
O ficheiro que transferiu é 100% SEGURO e livre de malware.

Para prosseguir com a instalação:
1. Clique no texto pequeno «Mais informações».
2. Clique no botão que aparecerá no canto inferior direito «Executar assim mesmo».

A mensagem desaparecerá para sempre.

=== ATUALIZAÇÕES DE SOFTWARE ===
Nunca precisará de verificar manualmente se há novas versões.
Titan está equipado com um sistema inteligente que verifica
as atualizações no arranque. Se uma versão mais recente estiver disponível,
verá aparecer um aviso (Toast) dentro da aplicação.
