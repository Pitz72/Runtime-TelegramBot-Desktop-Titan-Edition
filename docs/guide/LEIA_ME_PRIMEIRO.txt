=== INSTRUÇÕES DE INSTALAÇÃO RÁPIDA ===
Execute o arquivo de instalação. O software instalará a interface 
e criará automaticamente um atalho para iniciá-lo.
Na primeira inicialização, um Assistente de Configuração o guiará passo a passo.

*** ATENÇÃO USUÁRIOS DO WINDOWS (SMARTSCREEN) ***
Titan Edition é um software independente, distribuído sem
intermediários. Na primeira execução do arquivo ".exe", o Windows Defender
pode exibir uma tela azul com o texto:
"O Windows protegeu o seu PC - Fornecedor desconhecido".

Este é um procedimento normal de segurança do Windows para software
distribuído fora da Microsoft Store.
O arquivo que você baixou é 100% SEGURO e livre de malware.

Para prosseguir com a instalação:
1. Clique no texto pequeno "Mais informações".
2. Clique no botão que aparecerá no canto inferior direito "Executar assim mesmo".

A mensagem desaparecerá para sempre.

=== ATUALIZAÇÕES DE SOFTWARE ===
Você nunca precisará verificar manualmente por novas versões. 
Titan está equipado com um sistema inteligente que verifica 
atualizações na inicialização. Se uma versão mais recente estiver disponível,
você verá um aviso (Toast) aparecer dentro do aplicativo.
