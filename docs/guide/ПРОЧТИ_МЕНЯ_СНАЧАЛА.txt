=== ИНСТРУКЦИИ ПО БЫСТРОЙ УСТАНОВКЕ ===
Запустите установочный файл. Программное обеспечение установит интерфейс 
и автоматически создаст ярлык для его запуска.
При первом запуске Мастер настройки шаг за шагом проведет вас через весь процесс.

*** ВНИМАНИЕ ПОЛЬЗОВАТЕЛЯМ WINDOWS (SMARTSCREEN) ***
Titan Edition — это независимое программное обеспечение, распространяемое без
посредников. При первом запуске файла «.exe» Защитник Windows может
показать синий экран с текстом:
«Система Windows защитила ваш компьютер — Неизвестный издатель».

Это стандартная процедура безопасности Windows для программного обеспечения,
распространяемого вне Microsoft Store.
Загруженный вами файл на 100% БЕЗОПАСЕН и не содержит вредоносных программ.

Чтобы продолжить установку:
1. Нажмите на мелкий текст «Подробнее».
2. Нажмите на кнопку «Выполнить в любом случае», которая появится в правом нижнем углу.

Это сообщение исчезнет навсегда.

=== ОБНОВЛЕНИЯ ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ ===
Вам никогда не придется вручную проверять наличие новых версий. 
Titan оснащен интеллектуальной системой, которая проверяет наличие
обновлений при запуске. Если доступна более новая версия,
вы увидите уведомление (Toast) внутри приложения.


=== ПОДДЕРЖКА И ДОКУМЕНТАЦИЯ ===
Перед запуском программного обеспечения мы приглашаем вас прочитать «Краткое руководство»,
чтобы понять, как получить токен Telegram, необходимый для работы.
Для решения сложных технических вопросов (например, форматирование шаблонов или резервное копирование)
обратитесь к прилагаемому «Расширенному руководству пользователя».
