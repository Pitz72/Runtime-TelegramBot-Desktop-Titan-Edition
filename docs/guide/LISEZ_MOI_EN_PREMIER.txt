1. L'exécutable d'installation de Titan Edition (Setup.exe pour Windows ou .AppImage pour Linux).

=== INSTRUCTIONS D'INSTALLATION RAPIDE ===
Lancez le fichier d'installation. Le logiciel installera l'interface 
et créera automatiquement un raccourci pour le lancer.
Au premier lancement, un Assistant de Configuration vous guidera étape par étape.

*** ATTENTION UTILISATEURS WINDOWS (SMARTSCREEN) ***
Titan Edition est un logiciel indépendant, distribué sans
intermédiaires. Au premier lancement du fichier « .exe », Windows Defender
pourrait afficher un écran bleu avec le texte :
« Windows a protégé votre ordinateur - Éditeur inconnu ».

Il s'agit d'une procédure de sécurité normale de Windows pour les logiciels
distribués en dehors du Microsoft Store.
Le fichier que vous avez téléchargé est SÛR à 100% et sans malware.

Pour procéder à l'installation :
1. Cliquez sur le petit texte « Informations complémentaires ».
2. Cliquez sur le bouton qui apparaîtra en bas à droite « Exécuter quand même ».

Le message disparaîtra pour toujours.

=== MISES À JOUR DU LOGICIEL ===
Vous n'aurez jamais à vérifier manuellement les nouvelles versions. 
Titan est équipé d'un système intelligent qui vérifie la présence
de mises à jour au démarrage. Si une version plus récente est disponible,
vous verrez apparaître une alerte (Toast) dans l'application.
