# Runtime TelegramBot Desktop Titan Edition — Руководство по быстрому запуску

Добро пожаловать в **Runtime TelegramBot Desktop Titan Edition**. Это руководство поможет вам настроить первого бота и начать публиковать контент в вашем Telegram-канале за несколько минут.

---

## 1. Получение токена Telegram

Перед запуском приложения необходимо создать бота в Telegram:

1. Откройте Telegram и найдите **@BotFather** (с синей галочкой).
2. Отправьте команду `/newbot` и следуйте инструкциям для присвоения имени боту.
3. @BotFather вернёт вам **API-токен** (например, `123456789:ABCdefGHIjklMNOpqr...`). Скопируйте его.
4. Добавьте бота в свой Telegram-канал как **Администратора** с правом отправки сообщений.

---

## 2. Первый запуск — Настройка бота

При первом запуске нажмите **«+ Новый бот»** и заполните поля:

- **Имя** — название для идентификации бота в интерфейсе (например, *Новостной канал*).
- **Токен** — API-токен, предоставленный @BotFather.
- **Channel ID** — имя канала (например, `@мойканал`) или числовой ID для приватных каналов (например, `-100123456789`).
- **Дата начала** — бот будет игнорировать весь контент, опубликованный до этой даты. Полезно, чтобы не засыпать канал старыми статьями.

---

## 3. Добавление фидов (Feed Manager)

На панели управления ботом нажмите **«+ Добавить фид»**:

1. Укажите описательное **Имя** фида.
2. Выберите **Тип**: News, Podcast или YouTube.
3. Вставьте **URL**:
   - News / Podcast: URL RSS-фида.
   - YouTube: URL канала или хэндл (например, `@RuntimeRadio`). *API Key не требуется.*
4. Используйте **Проверить (⚡)** для проверки корректности ссылки, затем **Сохранить**.

### Расширенные параметры фида

- **Фильтр по ключевым словам** — Фильтрует статьи по ключевым словам для включения или исключения. Активируется в настройках фида. Янтарный бейдж указывает на активный фильтр.
- **Пользовательский интервал** — Устанавливает индивидуальный интервал получения данных для фида (от 5 минут до 24 часов), независимо от глобального интервала бота.
- **Digest Mode** — Вместо публикации каждой статьи по отдельности накапливает контент за настраиваемый период (1ч, 6ч, 12ч, 24ч, 7д) и отправляет его в одном сводном сообщении. Фиолетовый бейдж указывает на активный режим.
- **Импорт OPML** — Импортирует несколько фидов одновременно из стандартного файла `.opml` через кнопку OPML в Feed Manager.

---

## 4. Настройка сообщений (Template)

Перейдите в настройки бота → вкладка **Template**:

- Используйте **Smart Chips** для вставки динамических переменных: `{{title}}`, `{{link}}`, `{{summary}}`, `{{feedName}}` и др.
- Доступны 4 отдельных шаблона: Запуск, News, Podcast, YouTube.
- **Валидатор** сигнализирует об ошибках в реальном времени (несбалансированные теги, неизвестные чипы, небезопасные ссылки).
- Кнопка **Предпросмотр** показывает, как будет выглядеть сообщение с примерными данными, без выхода из редактора.

HTML-теги, поддерживаемые Telegram: `<b>`, `<i>`, `<code>`, `<a href="...">`.

---

## 5. Запуск — Ignition

Когда бот настроен и фиды добавлены:

- Нажмите кнопку **Play (▶)** в консоли.
- Кольцо состояния начнёт вращаться и бот запустится.
- На панели **System Logs** вы будете видеть в реальном времени получение фидов и публикацию в Telegram.

Для одновременного мониторинга нескольких ботов используйте переключатель **ALL BOTS / THIS BOT** в журнале.

---

## 6. Статистика

Нажмите иконку **Analytics (📊)** на панели управления для просмотра:

- Счётчики опубликованных статей: сегодня / за последние 7 дней / всего.
- Разбивка по фидам, отсортированная по объёму публикаций.

---

## Системные настройки

Доступны через иконку шестерёнки в правом верхнем углу:

- **Общие** — глобальный интервал проверки, тихие часы, язык.
- **Backup** — экспорт и восстановление базы данных.
- **Performance Mode** — отключает эффекты с высокой нагрузкой на GPU (скан-линии, размытие, свечение, анимации). Полезно на машинах с ограниченными ресурсами. Вступает в силу немедленно без перезапуска.

---

## Переносимость — файл .rtb

Для переноса бота на другой компьютер без потери настроек:

1. В настройках бота → **Экспортировать (.rtb)**.
2. Перенесите файл на новый ПК.
3. На новом ПК → **Импортировать (.rtb)** и введите токен повторно (токены привязаны к конкретной машине в целях безопасности).

---

## Устранение неполадок

- **Ошибки YouTube** — Google периодически обновляет свои серверы. Если на фидах YouTube появляются красные ошибки, временно отключите фид и дождитесь обновления приложения.
- **Недействительный токен** — Убедитесь, что бот добавлен в канал как администратор с правом отправки сообщений.
- **Linux без libsecret** — Приложение работает нормально, используя резервный метод AES-256-GCM. Для нативного хранилища ключей установите: `sudo apt-get install libsecret-1-0`.
