=== WAS IN DIESEM PAKET ENTHALTEN IST ===
1. Die ausführbare Installationsdatei der Titan Edition (Setup.exe für Windows oder .AppImage für Linux).
2. Den Ordner „Documentation“ mit den Pro-Benutzerhandbüchern (in 8 Sprachen) und der Kurzanleitung.

=== SCHNELLE INSTALLATIONSANLEITUNG ===
Führen Sie die Installationsdatei aus. Die Software installiert die Oberfläche 
und erstellt automatisch eine Verknüpfung zum Starten.
Beim ersten Start führt Sie ein Setup-Assistent Schritt für Schritt.

*** ACHTUNG WINDOWS-BENUTZER (SMARTSCREEN) ***
Die Titan Edition ist eine unabhängige Software, die ohne
Mittelsmänner vertrieben wird. Beim ersten Start der „.exe“-Datei zeigt Windows Defender
möglicherweise einen blauen Bildschirm mit der Meldung an:
„Der Computer wurde durch Windows geschützt – Unbekannter Herausgeber“.

Dies ist ein normales Windows-Sicherheitsverfahren für Software,
die außerhalb des Microsoft Stores vertrieben wird.
Die von Ihnen heruntergeladene Datei ist 100% SICHER und frei von Malware.

Um mit der Installation fortzufahren:
1. Klicken Sie auf den kleinen Text „Weitere Informationen“.
2. Klicken Sie auf die Schaltfläche, die unten rechts erscheint: „Trotzdem ausführen“.

Die Meldung wird für immer verschwinden.

=== SOFTWARE-UPDATES ===
Sie müssen nie wieder manuell nach neuen Versionen suchen. 
Titan ist mit einem intelligenten System ausgestattet, das beim Start
auf Updates prüft. Wenn eine neuere Version verfügbar ist,
sehen Sie eine Benachrichtigung (Toast) innerhalb der Anwendung.

=== SUPPORT UND DOKUMENTATION ===
Bevor Sie die Software starten, laden wir Sie ein, die „Kurzanleitung“ zu lesen,
um zu verstehen, wie Sie das für den Betrieb notwendige Telegram-Token erhalten.
Für fortgeschrittene technische Fragen (z. B. Vorlagenformatierung oder Backup) konsultieren Sie 
das beigefügte „Erweiterte Benutzerhandbuch“.
