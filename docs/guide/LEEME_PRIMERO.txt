1. El ejecutable de instalación de Titan Edition (Setup.exe para Windows o .AppImage para Linux).

=== INSTRUCCIONES DE INSTALACIÓN RÁPIDA ===
Ejecuta el archivo de instalación. El software instalará la interfaz 
y creará automáticamente un acceso directo para iniciarlo.
En el primer inicio, un Asistente de Configuración te guiará paso a paso.

*** ATENCIÓN USUARIOS DE WINDOWS (SMARTSCREEN) ***
Titan Edition es un software independiente, distribuido sin
intermediarios. En el primer inicio del archivo «.exe», Windows Defender
podría mostrar una pantalla azul con el texto:
«Windows protegió su PC - Editor desconocido».

Este es un procedimiento normal de seguridad de Windows para el software
distribuido fuera de la Microsoft Store.
El archivo que has descargado es 100% SEGURO y libre de malware.

Para continuar con la instalación:
1. Haz clic en el texto pequeño «Más información».
2. Haz clic en el botón que aparecerá en la parte inferior derecha «Ejecutar de todas formas».

El mensaje desaparecerá para siempre.

=== ACTUALIZACIONES DE SOFTWARE ===
Nunca tendrás que buscar manualmente nuevas versiones. 
Titan está equipado con un sistema inteligente que comprueba
si hay actualizaciones al iniciar. Si hay una versión más reciente disponible,
verás aparecer un aviso (Toast) dentro de la aplicación.
