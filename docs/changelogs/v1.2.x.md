# v1.2.0 — UX, Security, i18n & Backup (2026-02-24)

## 🆕 Nuove Funzionalità

### 🚀 Nuova Schermata di Avvio (Intro Screen)
- **Titan Splash sempre attiva:** L'app ora mostra un'affascinante schermata di accoglienza ad ogni avvio (con animazioni fluide Framer Motion e backglow dinamico).
- **Controllo Immediato:** Dalla schermata l'utente seleziona subito la sua lingua preferita e clicca su "Lancia Titan" per avviare il motore bot locale, bypassando i vecchi check rudimentali.

### 🌍 Internazionalizzazione (i18n) a 8 Lingue
- **Supporto multi-lingua Massivo:** Introdotta la possibilità di scegliere tra ben 8 idiomi supportati globalmente (Inglese, Italiano, Francese, Tedesco, Spagnolo, Portoghese, Russo, Cinese).
- **Dizionari dedicati:** Tradotti in tutte le combinazioni tutti i pannelli, dai BotSettingsModal al FeedManager fino al SetupWizard.
- **Iconografia Naturale:** Disegnati 8 loghi vettoriali SVG per ciascuna bandiera senza l'intralcio delle native emoji di sistema (spesso difettose su Windows).
- **Provider Contestuale Custom:** Integrazione fluida e senza dipendenze pesanti grazie all'uso di un `I18nProvider` leggero.
- **Salvataggio preferenze:** La lingua scelta viene salvata e ripristinata ai successivi avvii tramite `localStorage`.

### 💾 Backup & Ripristino (Import/Export Dati)
- **Esportazione Database SQL:** Possibilità di esportazione del database completo (`.db`) tramite i System Settings.
- **Ripristino Database SQL:** Possibilità di selezionare un database sqlite da importare; l'app effettua l'overwrite e invoca un riavvio totale per applicare i cambiamenti in sicurezza.
- **Esportazione Configurazione parziale (JSON):** Possibilità di estrarre le configurazioni dei Bot ed i relativi Feed in un comodo file JSON condivisibile.
- **Importazione Configurazione (JSON):** Il file JSON esportato può essere reimportato, accodando e creando i feed ai bot già esistenti, o creandoli in modo nativo sul momento.
- I bot importati da JSON partono disattivati di default.

### 🔒 Sicurezza: Cifratura Token
- **Cifratura end-to-end SQLite:** Il token di accesso dei Bot viene ora conservato interamente crittografato nel file `database.sqlite` servendosi del modulo sperimentale `safeStorage` di Electron.
- In ogni riga dei bot memorizzata, il token è illeggibile, proteggendo così il Controllo Bot da accessi abusivi al DB.
- **API IPC dedicate:** La comunicazione tra i processi non espone mai la password di decrittografia o il sistema integrato, decodificando in ram solo quando strettamente necessario, per passarlo allo strato view React (es. form di edit bot).
- **Retrocompatibilità:** Al primissimo avvio i Token ancora in chiaro nel Database vengono convertiti al volo crittografandoli tramite uno script di on-boot `encrypt-tokens`.

### ⚠️ UX Migliorata: Notifiche e Conferme
- **Framer Motion Toasts:** Rimpiazzati gli odiosi `alert()` nativi di Windows con delle notifiche Toast fluttuanti integrate tramite library framer-motion.
- **Danger Zone Modals:** Qualsiasi azione distruttiva (cancellare un profilo bot, azzerare lo storico dei post o eliminare una sorgente RSS) passa ora da un `ConfirmDialog` estetico con sfondo oscurato.
- Rimossi per intero i `confirm()` bloccanti forniti dal Browser.

## 🔧 Qualità del Codice

### 🌐 SystemSettingsModal
- **Riorganizzazione visiva:** Aggiunto un modal dedicato visibile dall'header, nel quale l'utente gestisce in maniera ordinata Sistema (Lingua, Backup Database, Export Conf). Impostando così le basi per versioni e funzionalità sistemistiche in espansione.

### 🔄 Modulo Storia Broadcast "Clear"
- Completata la funzionalità "Resetta Storico Pubblicazioni" nel pannello avanzato del Bot. Che ripulisce integralmente la tabella `history` e permette di resincronizzare e pubblicare tutti gli episodi senza limiti per l'utente, previo avviso in UI ("La Danger Zone").
