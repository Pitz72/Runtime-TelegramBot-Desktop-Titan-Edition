# Runtime TelegramBot Titan Edition — Changelog v1.7.2

**Data di Rilascio:** 2 Marzo 2026

## 🛡️ Graceful Degradation: Sistema di Allerta per YouTube

A causa di recenti ed improvvise variazioni nelle strutture interne e nelle API non documentate di YouTube, il sistema di `fetching` dei video risulta momentaneamente compromesso, generando tentativi falliti in loop.

Per salvaguardare la stabilità di Titan, è stato integrato un meccanismo di **Graceful Degradation**:
*   **Intercettazione a Basso Livello**: `BotEngine` ora identifica proattivamente i fallimenti specifici della sorgente feed di tipo `youtube` direttamente nel blocco `catch` del processing rate-limited.
*   **System Alert Non Bloccante**: Al verificarsi del fallimento, un Evento IPC (`youtube-api-error`) viene irradiato silenziosamente a tutte le finestre del processo `renderer` in esecuzione.
*   **Notifica Utente (UI Toast)**: La `Dashboard` intercetta l'evento mostrando un *Toast* d'errore (tradotto opportunamente via i18n) per notificare graficamente l'utente della situazione, suggerendo di disattivare il feed YouTube nell'attesa di un aggiornamento del Core software, prevenendo lo spam incontrollato nella console dei log.
*   **Gestione Stato Efficiente**: L'allerta grafica viene triggertata una sola volta per sessione/run, e si resetta coerentemente ad ogni nuovo avvio (`start/stop`) del motore bot.
