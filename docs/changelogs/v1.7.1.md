# Runtime TelegramBot Titan Edition — Changelog v1.7.1

**Data di Rilascio:** 1 Marzo 2026

## 🪲 Hotfix e Ottimizzazioni

*   **Risolto Bug Coercizione URL Parser (Legacy Code)**
    *   È stato rimosso un blocco di codice _legacy_ nel motore di `rss-parser` che forzava gli URL del dominio "runtimeradio.it" a trasformarsi staticamente in ".com".
    *   I link estratti dal nodo `<link>` dei documenti RSS/XML ora non subiscono alterazioni e vengono onorati fedelmente nella loro forma originale, rispettando le estensioni e le stringhe originarie volute dall'autore.
    *   Sistemato il _Domain Fallback_ per le immagini caricate nei nodi Enclosure: In assenza di origin path per rawUrl relativi (path che iniziano per `/`), il parser non fa più affidamento a stringhe hardcoded ma risolve l'origin in modo dinamico analizzando la feedUrl matrice.
