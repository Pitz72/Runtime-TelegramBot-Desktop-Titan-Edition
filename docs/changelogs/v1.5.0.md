# Changelog - Runtime TelegramBot Titan Edition v1.5.0

**Data di Rilascio:** 27 Febbraio 2026

## Novità e Miglioramenti 🚀

- **Editor Template Personalizzati (UI):** Aggiunta interfaccia utente completa per la personalizzazione dei messaggi su Telegram! Ora ogni bot supporta template dedicati per ciascuna tipologia di post (News, Podcast, YouTube).
- **Nuovo Designer "TemplateEditor":** Integrata un'area di formattazione avanzata dotata di:
  - Inserimento smart dei placeholder (`{{title}}`, `{{link}}`, `{{feedName}}`, `{{summary}}`) nel punto esatto del cursore testuale tramite "Smart Chips".
  - Design "Sci-Fi" scuro ispirato all'interfaccia di Titan Desktop, con styling coesivo, hover state traslucenti e field testuali scrollabili esteticamente appaganti (`custom-scrollbar`).
- **BotSettingsModal Refactoring:** L'interfaccia di configurazione bot si è modernizzata. È stata rimossa la pesantezza visiva introducendo un sistema di Navigazione Tabbed (`Generale` e `Template`). Le impostazioni principali restano fluide a due colonne, mentre una pagina dedicata racchiude tutti i template testuali.
- **Localizzazione UI:** Sono stati aggiornati entrambi i moduli I18n (`it.json` ed `en.json`) per supportare il nuovo tab system, i tooltips dell'editor ed i messaggi di hint per l'uso di HTML base consentito da Telegram.
- **Supporto Core Backend:** Connesso tutto l'impianto UI al backend (v1.4.2) per permettere il salvataggio full-stack delle opzioni inserite tramite chiamata IPC `updateBot`.


## Ritocchi 🛠️
- Rimossa vecchia documentazione obsoleta (`1.0.5_YOUTUBE_STATUS.md`).
- Fixata logica di fallback: i default interni per il rendering scattano ancora automaticamente se non è presente un pattern utente, senza richiedere interventi manuali.
