# Changelog - Runtime TelegramBot Titan Edition v1.5.2

**Data di Rilascio:** 27 Febbraio 2026

## Fix Critici 🐛

- **Risoluzione "Ghost Process" (Schermo Invisibile):** Risolto un grave problema noto su Windows dove Titan Desktop si avviava in background occupando memoria ma senza mai mostrare la finestra grafica.
- **Disabilitazione Accelerazione Hardware:** Implementato `app.disableHardwareAcceleration()` nelle primissime fasi di boot. Questo previene i crash silenti della GPU causati da driver obsoleti o da esecuzioni all'interno di Macchine Virtuali / VPS (scenario tipico per i bot server).
- **Gestore Errori Globali Nativo:** Aggiunti intercettatori profondi per `uncaughtException` e `unhandledRejection`. Ora, se il Main Process di Node.js va in panico prima del rendering UI, l'app non resterà più "appesa" in background all'infinito, ma mostrerà un popup di errore di sistema nativo di Windows prima di auto-terminarsi coerentemente (`app.exit(1)`).
- **Fallback Caricamento UI:** Se il caricamento del file `index.html` compilato dovesse fallire (es. build corrotta o permessi disco mancanti), l'app avviserà l'utente con una dialog nativa e si chiuderà, anziché restare un processo fantasma trasparente.
- **Timeout di Sicurezza "Anti-Ghost":** Aggiunto un paracadute temporale di 10 secondi. Se per qualche motivo di latenza del sistema operativo l'evento Electron `ready-to-show` non dovesse mai scattare, la finestra verrà forzata ad apparire ugualmente per evitare di bloccare l'utente.
