# v1.4.0 — Desktop Notifications (2026-02-26)

## Novità e Miglioramenti 🚀
- **Notifiche Desktop Native:** Implementato il supporto per le notifiche di sistema native OS. Ora, ogni volta che un post viene pubblicato con successo su Telegram, Titan mostrerà una notifica nativa sul desktop (OSX, Windows, Linux).
- **Gestione Notifiche per Singolo Bot:** L'utente può abilitare o disabilitare le notifiche individualmente per ogni bot direttamente dalla videata di "Configurazione Bot" (Bot Settings).
- **Aggiornamento Database:** Introdotta la `user_version 2` per il database SQLite che include la colonna `notifications_enabled` e migrazione automatica senza perdita di dati per gli utenti esistenti.
- **UI/UX:** Aggiunto un nuovo selettore a switch e tooltips dedicati nella modale di impostazioni per le notifiche desktop, con pieno supporto al multilingua.
