# Runtime TelegramBot Titan Edition — Changelog v1.7.0 "OmniSync"

**Nome in Codice:** "OmniSync"
**Data di Rilascio:** 28 Febbraio 2026

La versione **1.7.0 "OmniSync"** rappresenta uno dei traguardi infrastrutturali più importanti per Titan Desktop, introducendo un ecosistema di esportazione e salvataggio dei profili bot completamente rivisto, unificato sotto un formato proprietario sicuro, ed un'interfaccia utente (UI) profondamente rinnovata sia per l'estetica che per la navigazione globale.

## ✨ Novità Principali (Features)

*   **Esportazione e Importazione Granulare dei Bot (`.rtb`)**
    *   È ora possibile **esportare un singolo bot** configurato (inclusi i suoi feed RSS/Podcast/YouTube e le impostazioni specifiche) direttamente dalla sua finestra di modifica (`BotSettingsModal`).
    *   Introdotto il nuovo formato proprietario certificato **`.rtb` (Runtime Telegram Bot)**. Lavorando "sotto il cofano" come formato JSON ultra-veloce, garantisce pulizia e immediata compatibilità visiva dei salvataggi sui sistemi operativi desktop.
    *   Sistema di **Importazione Smart**: Selezionando un file `.rtb` salvato precedentemente (o ricevuto da un collaboratore), questo verrà iniettato all'interno dell'app. Qualora il bot importato esista già, il motore ne eviterà l'overlapping se gli id collidono, oppure accodandolo come muovo e autoselezionando la riga appena importata nella colonna di sinistra in automatico.
*   **Decriptazione Sicura dei Token in "Cross-Machine"**
    *   Sicurezza proattiva: I file esportati decriptano temporaneamente il token segreto in RAM durante l'export, per permetterne la lettura al volo nel file testuale offline. All'atto dell'importazione su una **macchina differente**, Titan applica automaticamente un nuovo livello di crittografia basato sull'Hardware ID del PC ricevente. I tuoi token restano bloccati all'interno della safeStorage ma interscambiabili in ufficio.

## 🛠️ Refactoring UI e UX Design

*   **Pannello "Impostazioni di Sistema" a Tab (Multi-Navigation)**
    *   Il `SystemSettingsModal` globale (l'ingranaggio in alto) ha ricevuto un profondo svecchiamento di design.
    *   La schermata è ora divisa in **due Tab fluide e scattanti**:
        *   **"Generale"**: Contiene lo switcher immediato per modificare la lingua su tutta l'APP, ora racchiuso in una card indipendente.
        *   **"Dati e Backup"**: Accentratore per tutte le operazioni vitali. Dal Backup totale dell'SQLite (`titan.db`) fino ai profili.
*   **Deprecati i file generici `.json` di configurazione dall'interfaccia UI!**
    *   In accordo al nuovo ecosistema, tutti i vecchi tasti per l'Import/Export *Globale* del parco bot non menzionano più, né consentono l'apertura indiscriminata di file `.json` generici. I picker e gli OS dialogs accettano rigorosamente ed esclusivamente i nuovi bundle **`.rtb`** pre-validati, per limitare errori utente e corruzioni. Il tasto "Importa JSON" è diventato un più organico **"Importa Profili / Esporta Tutti i Bot"**.

## 🌐 Mantenimento Multi-Lingua Globale (i18n)

*   Allineati a **zero-string-hardcoding** i file delle lingue master. I nuovi bottoni (*"Esporta in .rtb"*, *"Condivisione"*, indicatori *"Importa"*) così come i messaggi di *Toast* di Sistema, sono stati estratti nel motore Multi-Lingua ed estesi nativamente nelle 8 lingue supportate di base dal software:
    *   Italiano (Master)
    *   Inglese
    *   Spagnolo
    *   Francese
    *   Tedesco
    *   Portoghese
    *   Russo
    *   Cinese

## 🪲 Bug Fix e Ottimizzazioni Shadow

*   **YouTube Scraper Hotfix (Risoluzione Blocchi Prematuri):**
    Introdotto filtro logico nel modulo parser per impedire all'Engine di inviare prematuramente gli avvisi di dirette streaming YouTube programmate (`is_upcoming`) o di video Premiere ancora non terminati/pubblicati dallo youtuber, sanando così fastidiosi bug di anteprima sui canali Telegram. (Introdotto precocemente come hotpatch dalla v1.5.4).
*   Azzerati avvisi superflui di typescript grazie al controllo puntiglioso durante la migrazione a vite/electron.
