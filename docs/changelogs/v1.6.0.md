# Runtime TelegramBot Titan Edition — Changelog v1.6.0

**Data di Rilascio:** 28 Febbraio 2026

## 🌟 Novità: Condivisione Profili Bot (Import/Export `.rtb`)
In questa versione abbiamo introdotto una funzionalità richiesta per migliorare l'operatività multi-postazione: l'**Esportazione e Importazione Granulare dei Bot**.

*   **File `.rtb` (Runtime Telegram Bot):** È ora possibile esportare un singolo profilo Bot (comprensivo di tutti i suoi Feed, Link, Intervalli di controllo e Template grafici personalizzati) generandolo in un formato proprietario autoinstallante (estensione `.rtb`).
*   **Crittografia Dinamica:** Durante l'esportazione, il file salva i parametri in modo trasparente; in fase di importazione su un *nuovo* computer, l'engine re-cripta automaticamente il `Bot Token` sfruttando le API `safeStorage` di sistema (utilizzando la chiave hardware univoca della nuova macchina ospite).
*   **Esportazione:** Pulsante dedicato "Esporta" nella zona di condivisione all'interno del "Bot Settings Modal".
*   **Importazione:** Pulsante rapido (FileDown icon) nella top-bar del "Bot Selector" principale.
*   **Associazione OS:** I file `.rtb` sono ufficialmente registrati come profili Titan nel sistema operativo nativo (Windows/Linux/Mac).

## Fix & Miglioramenti Precedenti (v1.5.4) 🚀
Questa release condensa ufficialmente anche il cruciale hotfix implementato nel micro-step precedente:
*   **Filtro Anti-Premiere YouTube (Motore Core):** Implementato un filtro rigoroso alla radice del parser YouTube (`youtubei.js`) per scartare alla fonte i video contrassegnati come "Premiere" (`is_premiere: true`, "Premiere in 2 days", ecc.) o "Programmati" (`is_upcoming: true`).
    *   *Prima:* Il bot captava in anticipo i video posizionati erroneamente nella griglia alta di YouTube come "già disponibili", spammandoli su Telegram.
    *   *Ora:* L'engine ignora l'evento proattivamente tramite analisi testo/booleana, lasciando dormire il bot.

## 🔧 Dettagli Tecnici
* Frontend: Interfacce implementate in `BotSettingsModal.tsx` e `BotSelector.tsx`.
* Backend: Nuova gestione import/export DB manager bypass su `manager.ts` e mapping API.
* Core: Modifiche filtri `youtubei` in `youtube.ts`.
