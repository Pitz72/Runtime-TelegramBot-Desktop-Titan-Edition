# Titan Edition v1.7.6

## Nuove Funzionalità
- **Guide Rapide In-App**: Integrazione delle Quick Start Guide direttamente all'interno dell'interfaccia utente.
- Nuovo lettore Markdown nativo (`react-markdown`) integrato nel terminale sci-fi tramite il componente `QuickGuideModal`.
- Supporto multilingua completo per la documentazione in 8 lingue (EN, IT, FR, DE, ES, PT, RU, ZH), mappato coerentemente con la selezione della lingua dell'applicazione.
- Accesso rapido alle guide sia dalla `IntroScreen` (Setup iniziale) che dalla `Dashboard` principale (accanto alle preferenze).

## Altre Modifiche
- Aggiornati i dizionari i18n con il supporto al nuovo componente.
- Nuovi stili CSS dedicati in `index.css` per ottimizzare la lettura Markdown conservando il design dark sci-fi.
- Rigorosa ottimizzazione del `.gitignore` in root per le procedure di esportazione e build.

## Bug Fix & Rollback
- Al fine di preservare le prestazioni e la stabilità visiva dell'interfaccia terminale, la funzionalità "Guide Rapide In-App" è stata **rimossa** per conflitti nativi di render flexbox e overflow con lo sfondo animato. La pulizia del codice ripristina l'integrità strutturale prevendendo bug di visualizzazione.
