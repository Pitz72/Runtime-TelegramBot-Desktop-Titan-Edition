# Changelog - Runtime TelegramBot Titan Edition v1.4.2

**Data di Rilascio:** 27 Febbraio 2026

## Novità e Miglioramenti 🚀

- **Infrastruttura per Template Personalizzati (Fase 1 - Backend):** Predisposto il core dell'applicazione per supportare la futura integrazione di template di messaggi personalizzabili dall'utente per ciascun tipo di feed (Podcast, News, YouTube).
- **Consolidamento Logica di Invio:** Ottimizzato il modulo di comunicazione con le API di Telegram (`telegram.ts`). Le vecchie funzioni specifiche di formattazione (`sendEpisode`, `sendNews`, `sendVideo`) sono state accorpate e sostituite da un unico engine di parsing dinamico centrale (`sendFormattedMessage`), capace di iniettare dinamicamente i placeholder (`{{title}}`, `{{link}}`, `{{feedName}}`, `{{summary}}`).
- **Retrocompatibilità:** In assenza di template custom, il sistema applica autonomamente dei default stilistici consolidati per garantire continuità visiva.

## Modifiche Tecniche 🛠️

- **Aggiornamento Database:** Portata la `user_version` di SQLite alla `4`. Aggiunte tre nuove colonne alla tabella `bots`:
  - `template_podcast` (TEXT)
  - `template_news` (TEXT)
  - `template_youtube` (TEXT)
- **Aggiornamento Tipi e IPC:** Espansi gli interi layer `BotConfig`, le entity IPC in `preload` (rendere le nuove signature disponibili nei bridge Node/React), e aggiornati i metodi `createBot` e `updateBot` nel gestore `BotManager` per il passaggio passivo dei template salvati in memoria.
