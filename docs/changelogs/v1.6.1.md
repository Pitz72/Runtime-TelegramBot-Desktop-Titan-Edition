# Runtime TelegramBot Titan Edition — Changelog v1.6.1

**Data di Rilascio:** 28 Febbraio 2026

## 🌐 Mantenimento Multi-Lingua (i18n Hotfix)
Con la minor release 1.6.1 il team ha effettuato un audit qualitativo massivo sull'interfaccia utente (UI) dopo l'introduzione massiva del layout v1.6.0.

*   **Pulizia Hardcode:** Estratte preziose stringhe di testo grezzo da `BotSelector.tsx` e `BotSettingsModal.tsx` originariamente rilasciate in sola lingua italiana (zona Condivisione, Alert Toast "Importazione/Esportazione").
*   **Supporto 8 Lingue Completato:** Tutte le etichette, bottoni (es. "Ordina", "Azzera", "Esporta", "Importa") e i messaggi Toast di sistema nativi ora supportano fluentemente il mapping contestualizzato per le lingue:
    *   Italiano (`it.json`)
    *   Inglese (`en.json`)
    *   Spagnolo (`es.json`)
    *   Francese (`fr.json`)
    *   Tedesco (`de.json`)
    *   Portoghese (`pt.json`)
    *   Russo (`ru.json`)
    *   Cinese (`zh.json`)
*   **Nessun Effetto Collaterale:** Compilazione e check sintattico completati con successo per una stabilità frontend immutata.
