# Changelog - Runtime TelegramBot Titan Edition v1.5.3

**Data di Rilascio:** 27 Febbraio 2026

## Fix Critici 🐛

- **Prevenzione Crash Database (Nuove Installazioni):** Risolto un bug logico gravissimo che affliggeva i nuovi scaricamenti dell'app (fresh install). Nelle installazioni pulite, la creazione del database generava le tabelle già con tutte le colonne all'ultimo livello disponibile ma la transazione faceva scattare egualmente le routine di transizione (migrations), comportando l'esecuzione coatta di `ALTER TABLE ADD COLUMN` e mandando in crash l'applicazione col noto errore `SqliteError: duplicate column name`.
- **Prevenzione Corruzioni:** Riscritto integralmente l'onboarding delle migrazioni SQLite `user_version` iniettando blocchi `try/catch` per tollerare e ignorare la presenza preventiva di colonne aggiunte da fork esterni.
- **Ottimizzazione Bootstrap:** Ora la routine di backup del database locale di sicurezza non agisce a vuoto qualora l'applicazione stia partendo da `.db` vergine appena inizializzato in RAM e non ancora flushato con commit validi.
