## 🐛 Bug Report
L'utente ha segnalato la presenza del testo `u200b` all'inizio dei messaggi Telegram, seguito dall'URL dell'anterprima immagine.
Esempio: `u200b (https://...)È uscito un nuovo episodio...`

### Analisi
Il problema risiedeva nell'escape errato del carattere *Zero Width Space* (`\u200b`) usato nell'hack per le anteprime delle immagini.
Codice errato: `f"[\\u200b]({image_url})"` (doppio backslash -> escape letterale).
Questo causava rendering errato su alcuni client o situazioni, mostrando il backslash o corrompendo la sintassi MarkdownV2.

## 🛠️ Modifiche Apportate
- **src/bot.py**:
  - Corretto `f"[\\u200b]..."` in `f"[\u200b]..."` (singolo backslash per unicode escape corretto in Python).
  - Applicato a `create_improved_message` e `create_improved_message_with_feed`.

- **Versioning**:
  - Bump versione a **v2.0.3 "Phantom"**.
  - Aggiornati header in tutti i file.
  - Aggiornato CHANGELOG.md.

## 🧪 Verifica
La correzione utilizza la sintassi standard Python per caratteri unicode nelle f-string. Questo assicura che venga inviato il carattere invisibile corretto invece di una sequenza di escape letterale.
