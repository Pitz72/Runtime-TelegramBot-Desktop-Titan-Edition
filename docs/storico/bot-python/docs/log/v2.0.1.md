## 📝 Riepilogo Modifiche

### 1. Supporto Feed Azuracast
Implementato supporto completo per feed generati da Azuracast (es. "MICHELA DE PAOLA'S MONO 2026").
- **Problema**: I feed Azuracast hanno tag `<link>` vuoti e immagini in `<itunes:image>` o `<media:content>` invece che nel tag standard.
- **Soluzione Implementata (`src/bot.py`)**:
    - `extract_link_from_entry()`: Se il link principale è vuoto, usa automaticamente il link del file audio (`<enclosure>`) o MP3.
    - `extract_image_from_entry()`: Supporto avanzato per estrarre immagini da `itunes:image`, `media_content` e oggetti `image` complessi.
    - **Force Preview**: Aggiunto "link invisibile" (`[\u200b](url_immagine)`) all'inizio del template messaggio MarkdownV2 per forzare Telegram a generare l'anteprima dell'episodio.
